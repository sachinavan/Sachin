# 🕉️ Mahashivratri Special Animation - Full Stack Application

A beautiful, interactive full-stack web application celebrating Mahashivratri with stunning animations, real-time features, and community participation.

## 🌟 Features

### Frontend
- ✨ Smooth CSS animations
- 🌸 Dynamic flower falling effects
- 👥 Interactive deity animations (Shiva & Parvati)
- 💒 Wedding celebration animations
- 🎊 Confetti and sparkle effects
- 📱 Fully responsive design
- ♿ Accessibility support

### Backend
- 🔐 User authentication (JWT)
- 📊 Real-time statistics tracking
- 🔌 WebSocket real-time communication
- 💾 MongoDB database integration
- 📧 Email notifications
- 📸 File upload support
- 🛡️ Security middleware
- 📈 Visitor analytics

### Real-time Features
- 👥 Live user count
- 💬 Real-time chat
- 🎉 Celebration events
- 🌸 Shared flower animations
- 💒 Group wedding dance
- 🙏 Prayer sharing
- ✨ Blessing requests
